# Pick Your Poison

**Pick Your Poison** is a simple and friendly React app that lets users quickly check whether a food item is “good” or “bad” to eat. When you type an item into the search box, the background flashes:

- **Green** → the item is in the “good” category  
- **Yellow** → the item is in the “can eat it but its better not to abuse” category
- **Red** → the item is in the “bad” category    
- **Gray** → the item is not found in any category  

This provides a quick visual cue at a glance, making it easy to see what you can safely eat.
